# Parallax Website

> A layered motion study inspired by depth, atmosphere and responsive pointer interaction.

This experiment builds a cinematic **Zhangjiajie** scene from individually layered mountains, fog and lighting assets. Each layer moves at its own speed and depth, creating a perspective effect that responds to pointer movement while **GSAP** handles the opening sequence.

### motion study

`HTML` · `CSS` · `JavaScript` · `GSAP` · `Parallax`

**What I explored**

- multi-layer pointer-driven parallax
- perspective and `translateZ` depth
- subtle rotation based on cursor position
- independent motion speeds for scene layers
- GSAP-based entrance choreography
